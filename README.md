# 无限协作画布（infinite-canvas-server）

一个支持多人协作的在线无限画布，用来整理文本、图片、视频和附件，编辑图片、记录白板，并通过节点连线组织 API 工作流。

以下功能由本仓库的[协作版](https://github.com/huanxueshengmou/infinite-canvas-server/tree/codex/secure-collaboration)提供，页面入口为 `/collaboration`。

## 多人协作

- 自助注册、登录，创建自己的画布，邀请其他账户加入。
- 多人同步节点内容、位置和连线，显示协作者的用户名与鼠标位置。
- 分享支持只读或编辑权限、访问口令、到期时间和撤销授权。
- 同时修改同一节点时提示冲突，保留当前页面的编辑草稿供选择处理。

## 画布与节点

- 无限平移与缩放，双击空白画布打开节点类型和模板选择框。
- 支持文本、Markdown、图片、视频、文件、自定义节点、隐私 API 节点、画布组和白板。
- 支持框选、多选、复制粘贴、批量移动和删除，以及撤销、重做。
- 从输出端口拖到下游节点即可连线；连线可重接、断开，并随画布同步。
- 提供浅色、深色主题，工具栏和弹窗适配手机窗口。

## 图片、视频和文件

- 支持批量拖入、多选上传，以及从剪贴板粘贴图片、视频和文件。
- 选中的公开节点可在当前画布内复制粘贴；图片、视频和文件节点右键即可下载。
- PNG、JPEG、WebP、GIF 图片及 MP4、WebM 视频支持预览；不支持的后缀保留为下载附件，媒体解码失败时也提供下载入口。
- Markdown 节点支持编辑和预览，可导入 `.md`、`.markdown` 文件；超出单次同步上限时作为下载附件保留。

## 图片编辑

- 右键图片选择「编辑图片」，支持画笔、框选裁剪、箭头和文字标注。
- 可调整颜色、画笔粗细和字号，支持局部撤销、重做、缩放和平移。
- 完成后预览 PNG 结果，选择覆盖原图或复制到剪贴板，再粘贴到画布或其他应用。
- 覆盖只更新当前图片节点，保留旧文件以供撤销；原图被协作者更换时提示冲突。

## 画布组与白板

- 公开节点可编组，拖动组标题即可一起移动；支持成员移入、移出、复制整组和解散分组。
- 白板支持手写、箭头和多行文字，可调整颜色、粗细，并拖动右下角自由改变大小。
- 白板缩小后保留笔迹，放大可继续查看；笔迹和尺寸支持协作同步及撤销、重做。
- 白板和组没有输入、输出端口。

## API 工作流与模板

- 自定义节点支持文本拼接和 JSON 输出，连线可传递文本、JSON、图片或附件。
- 隐私 API 节点的配置与结果对其他协作者不可见；需要共享时，预览并发布选定结果到画布。
- 支持多种 HTTP 方法、JSON、URL 编码表单、multipart 文件表单、文本和 XML，以及自定义请求头和认证方式。
- 提供生图、参考图对话、视频和通用 API 模板；配置可保存为个人模板复用，视频任务可单独查询状态。

## 离线导出与导入

- 画布顶部选择「导出 HTML」，将节点、连线、分组、白板和全部附件打包成一个文件。
- HTML 可直接在浏览器离线打开，支持平移、缩放、图片查看、视频播放和附件下载。
- 在协作空间选择「导入 HTML」，还原为可继续编辑的新画布，保留布局、内容和文件；原画布保持不变。
- 隐私 API 节点保留位置和连线，私有配置与结果不导出，导入后需重新配置。
- 导入会校验格式和附件完整性；仅支持本应用导出的画布 HTML。媒体越多，导出文件越大。

## 服务管理与数据保存

- 文件默认上传上限为 500 MiB，管理员可在「服务管理」调整。
- API 域名白名单与黑名单可切换，两份名单独立保存。
- 协作数据库保存在服务器本机，文件与数据库备份加密保存，支持配置云盘存储和备份恢复。

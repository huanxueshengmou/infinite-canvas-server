# 多人协作服务

协作入口为 `/collaboration`，支持自助注册、邀请加入、实时文本 / 图片 / 视频 / 文件节点、带用户名的协作鼠标、节点连线和自定义节点模板，以及只有创建者可以读取和执行的隐私 API 节点。原有 `/canvas` 是本地画布，不会自动上传本地画布、模型配置、Agent 对话或 WebDAV 数据。

## 使用

1. 登录页点击「没有账户？立即注册」，填写用户名、密码及确认密码后自动登录。新账号为普通账户，可以创建自己的协作画布，不会自动获得其他画布或服务管理权限。
2. 画布所有者在「分享与权限」中选择只读或编辑权限、可选口令和到期时间。接收者登录后接受邀请，也可以通过链接注册并加入；口令错误、已过期或已撤销的邀请会明确拒绝。链接的令牌放在 URL fragment 中，页面读取后立即清除。
3. 普通节点的拖动和输入立即在本地显示，后台每 150 ms 合并提交。状态栏区分连接中、后台同步、已同步、离线及冲突。
4. 点击「隐私节点」，在私有窗口配置 HTTPS API 地址、密钥、请求方法和正文。支持 JSON、URL 编码表单、multipart、文本 / XML 与自定义请求头。「服务管理」默认启用域名白名单，也可切换为独立的黑名单模式。
5. 请求结果只回到创建者的私有窗口，不会自动生成公共节点。窗口在断网、切换标签页、离开页面或连接权限失效时关闭；未保存的内容会丢失。
6. 点击「节点模板」选择自定义文本 / JSON、生图、参考图对话、提示词优化或 AutoDL H3 视频。节点可修改参数并「另存节点模板」，自己的模板按账户加密保存，不复制 API 密钥。
7. 从节点右侧输出圆点拖到下游节点即可连线，也可指定端口。右键线直接断开，点击线可重连。Ctrl/⌘+拖拽框选、点击多选，选中后一起移动或删除；Ctrl/⌘+Z 撤销，Ctrl+Y / Ctrl/⌘+Shift+Z 重做。详细参数和示例见 [协作节点与模板](WORKFLOWS.md)。
8. 管理员在「服务管理」设置单文件上传上限，单位 MiB，默认 500。保存后对新上传生效，无需重启；调小不会阻止已有大文件下载。
9. 图片、视频、附件可批量拖入、多选上传或 Ctrl/⌘+V 粘贴；Ctrl/⌘+C 复制所选公共节点后可在当前画布粘贴，私有配置不会复制。右键图片 / 视频 / 附件节点选择下载，保留文件名。双击空白处打开节点类型与模板选择框，在该位置创建节点。
10. 右键图片选择「编辑图片」，用画笔、箭头、文本或框选裁剪标注；滚轮缩放，空格或中键平移。点击「完成编辑」预览 PNG，再选择「覆盖原图」或「复制到剪贴板」。覆盖只更新当前节点，保留旧文件以供撤销；原图被其他人改动时保留编辑结果并提示冲突。GIF 编辑输出为静态 PNG。
11. 选择公开节点后「编组」，或添加空的「画布组」再拖入节点。拖动组标题会移动全部成员，组框随成员大小和位置调整；右键成员可移出，右键组可解散并保留成员。复制组会复制成员并建立新分组，删除组会一并删除成员且先确认。分组不嵌套，不包含隐私节点。
12. 添加「白板」后可直接手写；选中后切换画笔、箭头、文本、颜色和粗细，输入文字后点击白板放置。拖动右下角调整大小，缩小只裁切可见区域，放大后仍保留笔迹；笔迹、尺寸和分组关系同步并可撤销。白板和组均无输入 / 输出端口。
13. 在画布顶部选择「导出 HTML」，下载含全部附件的单个离线页面；可在无服务器、未登录的浏览器里平移缩放、切换主题、查看图片和 Markdown、播放视频及下载附件。在协作空间选择「导入 HTML」，上传该文件并填写新画布名称，即可恢复为可继续编辑的新画布。

支持 PNG / JPEG / WebP / GIF 图片和 MP4 / WebM 视频预览；浏览器不支持的视频编码或损坏媒体会显示下载入口，其余后缀仅作为附件下载。Markdown 节点可编辑、预览，也可导入 `.md` / `.markdown`；超过既有单次同步上限的 Markdown 保留为下载附件。预览不执行 HTML，外部图片显示文字占位而不自动请求。

协作连线会传递上游文本、JSON 或附件；API 节点使用自己的私有配置执行。原本地画布的插件、脚本运行和 Agent 功能仍走本地流程，不会作为隐藏字段混入协作协议。协作自定义模板是声明式配置，不执行任意 JavaScript / Python，也不在低配服务器安装 ComfyUI 或运行 GPU 模型。

## 离线画布文件

- 导出前等待当前编辑同步，再读取完整快照；节点位置、尺寸、内容、连线、分组、白板笔迹和公开附件均保留。相同文件引用只打包一次。
- 文件包含内联样式、浏览脚本、格式版本 `1` 的画布数据和 Base64 附件，不依赖 CDN 或原服务器。离线页面用于浏览；导入回协作空间后可继续编辑。
- 隐私 API 节点只保留固定标题、位置、尺寸和连线，不读取或打包私有配置、API 密钥及响应。导入后生成当前账户自己的空白隐私节点，需重新配置。成员、分享权限、会话和撤销历史不在导出范围内。
- 导入仅接受本应用导出的 HTML，先校验数据版本、节点和连线关系以及每个附件的长度和 SHA-256；网页脚本、外链资源和事件处理器不会在导入时执行。普通网页无法还原为节点。
- 导入始终创建新画布，重新分配节点、连线和文件 ID，再恢复引用；沿用服务器当前单文件上限和单次同步上限分批提交，不修改原画布。中断时明确提示，已创建的新画布和成功写入内容保留，可打开检查。
- 导出取消或附件读取失败时不下载残缺页面。Base64 使附件体积增加约三分之一，导出 / 导入还需要浏览器内存；大视频的实际可用规模取决于设备和浏览器，并非服务器单文件上限的保证。

## 同步和权限

- Node.js 24、Fastify 和 WebSocket 处理网络连接；SQLite 的读写、事务和本地磁盘同步在独立 Worker 中执行，使用 WAL 和 `synchronous=FULL`。
- 只广播变化的节点和连线。首次连接分帧发送快照；断线后重新鉴权并获取当前快照，客户端保留当前页尚未确认的草稿。
- 协作协议版本为 `5`，数据库保持版本 `3`。节点修改、文件上传、撤销 / 重做、隐私保存 / 执行 / 发布、模板修改与域名策略保存要求 `X-Canvas-Protocol: 5`，WebSocket 使用 `events?v=5`。缺少或不匹配版本的写入返回 409 且不保存，旧连接以 4001 关闭并提示刷新；升级后请重新加载页面。
- 节点版本检查拒绝过时写入；一批操作原子提交，冲突不覆盖他人内容。客户端可选择使用服务器内容，或确认把草稿应用到最新版本。
- 操作 UUID 与请求摘要用于去重，数据库提交成功后才确认保存。重试相同操作不会重复创建节点。
- 分享权限为 `viewer` / `editor`，管理权属于画布创建者。分享撤销、权限更改、成员移除、退出登录都会断开对应的在线连接；分享和登录到期也会断开。
- 移除成员后，如果仍允许使用原分享链接，成员可以再次申请加入；需要彻底收回链接授予的权限时，应同时撤销该链接。
- 鼠标以画布坐标同步，按 150 ms 合并广播，用户名取自登录会话；只读协作者也能显示鼠标。同账户多标签页合并成一个标记，离开画布、失焦、隐藏标签页或断开连接时移除，不写入 SQLite、不增加画布版本。
- WebSocket 负责快照、变化通知、在线人数和临时鼠标位置；所有内容修改通过带会话、来源与 CSRF 校验的 HTTP 接口处理。
- 连线在同一事务内校验节点归属、端口类型、单输入占用、版本和循环；过时重连明确失败，不覆盖其他人的修改。
- 撤销 / 重做使用当前账户的加密操作历史及版本检查，节点和关联线一起恢复；连续拖动合并为一次历史。不会回滚较新的私有配置或重复调用 API。前端在他人修改相关内容时使对应历史失效，刷新 / 重连后重置当前页面的撤销栈。
- 服务退出先停止 WebSocket 与正在执行的 API，再等待 HTTP 连接结束和数据库关闭，避免在线协作者阻塞部署切换。

## 隐私边界

公共数据有严格字段白名单。隐私节点在公共快照、操作回执和广播中仅有固定的「隐私节点」标题、节点 ID、位置、尺寸和版本，不含真实标题、备注、URL、密钥、请求正文或响应。画布所有者也不能经应用接口读取其他成员的隐私节点。

隐私节点的连线仅包含节点 ID、固定端口名和版本，不包含传递的实际数据。别人不能连接、重连或断开你的隐私节点；私有输出只能流向同一创建者的隐私节点。明确「发布所选结果」后，所选字段或媒体才生成公共节点；原始响应其余字段仍然私有。发布前检查结果版本，配置或结果变动时拒绝使用旧的确认。

隐私配置和结果使用 AES-256-GCM 加密，密文绑定画布、节点和创建者。云盘文件与数据库备份也加密；主密钥保存在服务器本地独立文件中，不写入云盘备份、Git 或日志。登录密码采用随机盐及 scrypt，登录与分享令牌只存摘要。会话 Cookie 使用 HttpOnly、Secure、SameSite=Strict，敏感响应不缓存。

API 请求和结果媒体获取使用管理员保存的同一域名策略，始终限制为 HTTPS 443。默认开启白名单，只允许完整域名；关闭时使用黑名单，同时阻止所列域名及其子域。两份名单独立保存，关闭白名单不会清空它。每次请求检查全部 DNS 解析结果，拒绝内网、回环、保留、链路本地和云元数据地址，并将通过校验的地址固定到实际 TLS 连接；不跟随重定向。响应中的当前 API 密钥及标记为秘密的请求头值会脱敏。获取媒体时不转发请求头密钥、会话 Cookie 或 Authorization。

这提供协作者之间的隔离和云盘静态数据保护，**不是端到端加密**：服务器需要解密并执行 API 请求，拥有服务器及主密钥的管理员仍具有解密能力。公共内容一旦已发送给别人，就不能远程收回其截图或副本。节点可见性创建后不能通过公共更新改为私有；请从一开始就使用隐私节点保存秘密。撤销历史同样按画布、账户和操作 ID 加密绑定；删除节点不会抹除已有操作历史或加密备份，保留与清理需由管理员管理。

协作页不加载分析脚本、第三方节点插件和本地 Agent 面板。服务器部署使用严格 CSP，不允许任意脚本、iframe 或第三方分析代码；本地画布中依赖第三方脚本或浏览器直连 API 的功能不属于该受限协作部署的兼容承诺。

## 已确认的默认配置

| 配置 | 默认值 | 达到限制时 |
| --- | --- | --- |
| 每画布在线连接 | 50 | 拒绝新增连接 |
| 单次同步请求 | 1 MiB | 拒绝，不截断 |
| 单文件 | 500 MiB，可在服务管理调整 | 明确失败，不保存截断内容 |
| API JSON / 文本响应 | 20 MiB，独立于文件上限 | 明确失败，不保存截断内容 |
| API 执行时间 | 120 秒 | 中止请求 |
| 会话 / 分享有效期 | 24 小时 / 默认 7 天 | 重新登录或重新授权 |
| 编辑合并间隔 | 150 ms | 本地即时显示，后台发送 |
| API / 文件处理并发 | 2 | API、上传繁忙时返回 429；下载在有界队列中等待，队列上限沿用 50 个连接的容量 |
| 登录速率 / 写入速率 | 每来源 10 次/分钟；每账户 600 次/分钟 | 返回 429 |
| 云盘备份周期 | 60 秒 | 失败会在服务管理中显示 |

参数均在 `.env.example` 中。单文件大小的数据库设置优先于环境变量 `MAX_FILE_BYTES`；API 响应单独使用 `MAX_API_RESPONSE_BYTES`，不会随上传上限提高。Nginx 仅在上传接口放开代理层请求体限制，应用仍先鉴权，再按当前设置流式限制每个文件。登录限流仅信任来自回环地址反向代理的转发 IP；后端必须绑定 `127.0.0.1`，网关覆盖传入的 `X-Forwarded-For`。API 与下载处理都不阻塞同步事件循环。

视频使用「提交任务 → 保留任务 ID → 按需查询」；不自动重试收费请求，也没有新增长时间轮询默认值。同一个隐私节点处理期间拒绝重复执行。HTTP 超时不代表上游已取消任务，应优先查询已有任务，避免重复计费。

注册接口沿用每来源每分钟 10 次的认证限流及原有密码校验；用户名不区分大小写，重复注册返回明确错误，不会覆盖现有账户。

## 服务器存储和部署

本次部署使用 `deploy/compose.yml` 和 `deploy/infinite-canvas.service`：

- 应用代码：`/opt/infinite-canvas`。
- 本地事务数据库和密钥：`/var/lib/infinite-canvas`，容器内 `/data`。
- 文件、备份和挂载标记：`/root/PDSDrive/团队空间/huanxue/infinite-canvas`，容器内 `/storage`。
- `files/*.enc` 为加密文件；`backups/*.sqlite.gz.enc` 为加密压缩备份，对应 JSON 清单标记备份完成并包含 SHA-256。
- 文件上传边读取边加密。下载先完整验证 GCM，并将密文暂存为本机 `download-UUID.enc`，随后流式解密发送；明文不落盘，传输完成或取消后清理。这样内存不会随 500 MiB 文件大小线性增长，也不会在认证失败前发送明文。完整校验会增加下载首字节等待；同时下载两个大文件需要本机容纳两份临时密文。
- 数据库版本 3 在连线与模板表之外增加加密操作历史。已有版本 1 / 2 会先在本地创建独立的 `canvas.sqlite.before-v3-UUID.sqlite` 备份，再增量迁移，保留账户、会话、节点、连线和文件引用；原有允许域名自动作为白名单读取。未知版本拒绝启动。回退旧服务时需在维护窗口恢复对应旧版本备份，不能让旧程序直接打开版本 3 数据库。
- FUSE/NFS/SMB 不可用作 SQLite 主库位置。挂载标记不存在或不正确时拒绝画布内容、隐私内容和文件写入，避免悄悄写入系统盘的空目录。
- 60 秒为备份调度间隔；云盘延迟或故障会拉大可恢复时间窗口。系统盘完全丢失时，应以「服务管理」显示的最近成功备份为准。本机正常重启使用已提交事务恢复。
- 应用与云盘挂载服务有启动依赖，开机检查挂载标记后重建应用容器，避免绑定到尚未挂载的空路径。
- 现有 FUSE 只允许 UID 0 访问，所以应用容器使用 UID 0，同时禁用所有 Linux capabilities、禁止新增权限、使用只读根文件系统，仅绑定本项目的数据目录，不挂载 Docker socket。

80 端口跳转至 HTTPS。使用 Let's Encrypt 的 IP 短期证书，不依赖域名；`infinite-canvas-cert-renew.timer` 每天两次触发续期检查，成功后校验并重载 Nginx。证书使用 `shortlived` profile，参见 [Let's Encrypt / Certbot IP 证书说明](https://letsencrypt.org/2026/03/11/shorter-certs-certbot/)。

常用运维命令：

```sh
systemctl status infinite-canvas mountapp
docker logs --tail 100 infinite-canvas-app
systemctl list-timers infinite-canvas-cert-renew.timer
docker exec infinite-canvas-app npm run backup
```

更新 `deploy/nginx.conf` 后需要重建网关容器，并核对容器内外的文件哈希。单文件 bind mount 可能仍指向旧文件，单独执行 Nginx reload 不能保证新配置生效；大文件上传规则必须在实际入口验证。

```sh
docker compose -f /opt/infinite-canvas/deploy/compose.yml up -d --no-deps --force-recreate gateway
docker exec infinite-canvas-gateway nginx -t
sha256sum /opt/infinite-canvas/deploy/nginx.conf
docker exec infinite-canvas-gateway sha256sum /etc/nginx/conf.d/default.conf
```

恢复流程应先在新的本地文件中验证，不能直接覆盖正在运行的主库：

```sh
docker exec infinite-canvas-app node scripts/backup.js restore \
  /storage/backups/完整文件名.sqlite.gz.enc /data/recovered.sqlite
```

恢复同时需要对应的 JSON 清单和原始 32 字节主密钥。工具拒绝覆盖现有恢复文件、拒绝校验和不符或认证失败的密文。检查恢复库 `PRAGMA integrity_check`、账户与节点数量后，在维护窗口停止应用，保留当前数据库及 WAL/SHM，再切换到恢复文件并启动。未知数据库版本或丢失密钥会拒绝启动，不会生成替代密钥覆盖旧数据。

账户密码遗失时，在维护窗口停掉应用，通过受保护的标准输入向 `scripts/create-admin.js --reset` 提供 `username` / `password` JSON，然后重新启动；这会使该账户旧会话失效，不改变其身份或节点归属。该命令只能由服务器运维人员执行。主密钥遗失且无离线副本时，无法恢复隐私内容与加密备份。

## 本地开发与验证

```sh
cd server
npm ci
# 按 .env.example 设置环境；开发默认绑定 localhost:8787，前端开发 origin 为 localhost:3000。
# 首次账户：将受保护的 username/password JSON 从标准输入传给 npm run create-admin。
npm start
```

另一个终端在 `web` 运行 `bun install --frozen-lockfile` 和 `bun run dev`。Vite 将 `/api` 和 WebSocket 代理到本地服务。静态生产文件需先在 `web` 执行 `npm run typecheck` 和 `npm run build`，再构建 `server/Dockerfile`。

```sh
cd server
npm test
npm run load-test
node scripts/large-files-test.js
```

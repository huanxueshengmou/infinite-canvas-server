## 服务器实测

机器为 2 核、约 1.8 GiB 内存；生成器与服务使用独立进程，在 768 MiB 限额的 Docker 测试容器内运行，生产服务同时保持在线。20 个独立账户保持连接，各执行 100 次编辑，并发送各自鼠标位置，共 2,000 次写入。协议 3 版本测试约 27.94 秒：

| 指标 | 结果 |
| --- | --- |
| 确认延迟 P50 | 79.00 ms |
| 确认延迟 P95 | 134.84 ms |
| 确认延迟 P99 | 173.99 ms |
| 最慢确认 | 226.90 ms |
| 服务端峰值 RSS | 151.6 MiB |
| 事件循环延迟 P95 | 13.00 ms |
| 事件丢失 / 最终分歧 | 0，全部客户端一致 |
| 具名鼠标 | 20 个，所有客户端用户名和最终坐标一致 |
| 广播中的私有哨兵 | 未发现 |

这是服务器内真实网络连接的文本及位置编辑压力测试，不含公网 RTT、20 个同时执行的 AI 请求或大文件压力。API / 文件处理并发为 2；默认 50 连接是准入配置，不代表已经完成 50 人负载验收。

## 本轮 500 MiB multipart 发送

服务器的独立 768 MiB 容器使用本地加密附件，经过完整认证、multipart 编码和流式解析，附件原始大小为 524,288,000 字节，请求总长为 524,288,418 字节。编码与解析约 8.01 秒，同进程峰值 RSS 165.8 MiB；解析后文件 SHA-256、重复字段与声明长度均一致，临时密文已清理。

该检查覆盖本轮新增的编码与读取路径；编码器与接收解析器处于同一进程，未连接真实供应商，也不代表公网或云盘吞吐。

## 500 MiB 文件上传与下载基线（协议 2）

在同一台服务器的独立 768 MiB 测试容器中，以本地临时数据库和指定团队云盘的独立测试目录验证；生产数据库和已有文件不参与测试。压力生成器与服务为独立进程，生成器使用遵循网络背压的字节流，分别记录内存：

| 项目 | 结果 |
| --- | --- |
| 单文件 524,288,001 字节 | HTTP 413，未留下截断文件 |
| 两路 524,288,000 字节上传 | 均为 HTTP 200，约 25.34 / 25.55 秒 |
| 两路 500 MiB 下载 | SHA-256 与原始内容一致，约 28.38 / 28.43 秒 |
| 完整认证后的首字节等待 | 约 14.96 / 15.11 秒 |
| 服务端峰值 RSS | 150.4 MiB |
| 压力生成器峰值 RSS | 139.6 MiB |
| 文件传输期间健康检查 P95 | 229.47 ms |
| 临时密文清理 | 处理槽释放后无下载缓存残留 |

本机独立测试也通过相同文件边界与哈希校验。以上速度来自服务器内网路径和当时云盘挂载状态，不代表公网带宽或后续云盘速度，也不将挂载报告的容量视为用户套餐容量的验证。20 人编辑测试与大文件测试分别进行，未声称 20 人同时生成视频或上传 500 MiB 文件。

正式入口另行通过受信任 HTTPS / Nginx 验证：精确 500 MiB 上传约 19.32 秒，下载约 15.28 秒且 SHA-256 一致；下载完整认证后的首字节约 8.06 秒，超出 1 字节返回 HTTP 413。连接在服务器内回到正式网关，保持证书验证，不代表公网上传速度。网关容器已重建，容器内外配置哈希一致；检查未发现无引用密文或下载缓存残留。

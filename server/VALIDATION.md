| 确认延迟 P95 | 125.21 ms |
| 确认延迟 P99 | 152.12 ms |

| 事件丢失 / 最终分歧 | 0，全部客户端一致 |

这是服务器内真实网络连接的文本及位置编辑压力测试，不含公网 RTT、20 个同时执行的 AI 请求或大文件压力。API / 文件处理并发为 2；默认 50 连接是准入配置，不代表已经完成 50 人负载验收。

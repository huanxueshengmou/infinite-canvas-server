# 协作节点与模板

在 `/collaboration` 的画布底部点击「节点模板」。自定义文本 / JSON 节点公开参与协作，图片、视频和通用 API 模板创建为隐私节点。API URL、密钥、参数和响应仅创建者可见。

## 连接节点

从上游右侧输出圆点拖到下游节点本体即可连接：文本与自定义输出接文本 / JSON 输入，图片接图片输入。文件或自己的隐私输出有多种可用输入时，会弹出输入类型选择；不会自动覆盖已占用的端口。也可直接拖到指定圆点，或先点击输出再点击输入。左侧端口从上到下依次为文本 / JSON、图片、音频。

**右键连线直接断开**，点击连线可重接输入或断开，Esc 取消正在创建的连线。断线同样可以撤销。

| 输入端口 | 可以连接 | 模板引用 |
| --- | --- | --- |
| 文本 / JSON | 文本、自定义节点、附件、自己的隐私输出 | `{{input.text}}`、`{{input.json.prompt}}` |
| 图片 | 图片节点、自己的隐私媒体结果 | `{{image.dataUrl}}` |
| 音频 | 音频文件、自己的隐私媒体结果 | `{{audio.dataUrl}}` |

每个输入端口接一条线，一个输出可以连接多个下游。节点必须在同一画布内，连线不能形成循环。版本冲突会报错；节点删除后，关联连线在同一事务中移除。连线及端点位置会同步给其他协作者。

公共节点可以输入自己的隐私节点。隐私输出只能接入同一创建者的隐私节点，不能直接接入公共节点或别人的隐私节点。工作流使用上游 API 已保存的成功结果，不自动再次调用收费接口；请先执行上游，再执行下游。

## 快捷键与多选

| 操作 | 快捷键 / 手势 |
| --- | --- |
| 撤销 | Ctrl/⌘+Z，或底部撤销按钮 |
| 重做 | Ctrl+Y、Ctrl/⌘+Shift+Z，或底部重做按钮 |
| 框选 | 按住 Ctrl/⌘ 在空白处拖动；同时按 Shift 保留已有选择 |
| 加入 / 移出选择 | Ctrl/⌘+点击节点标题或空白区域 |
| 全选 | Ctrl/⌘+A |
| 一起移动 | 选中多个节点后拖动其中一个标题 |
| 删除所选 | Delete / Backspace，确认后删除；也可点击「删除所选」 |
| 取消选择 | Esc，或点击画布空白处 |

连续拖动产生的多个同步批次合并为一次撤销，批量删除的节点与关联连线一起恢复。撤销和重做会同步给协作者，服务端重新检查版本、节点归属和连线规则；别人修改相关内容后，受影响的历史会失效或被拒绝，不会强行覆盖当前内容。其他人的隐私占位节点不能被选中后批量修改。

输入框内保留原生文字编辑快捷键。画布撤销处理节点的创建、公共内容、位置和连线，不会重新发送 API 请求，也不会把私有窗口中较新的配置或结果回滚。可操作的撤销栈保留在当前页面，刷新或重新连接后重置；服务器保存的操作历史加密存储，删除节点不等于抹除历史或备份。

## 自定义文本和 JSON

创建「自定义文本拼接」后，可将模板改为：

```text
请根据以下内容写一段图片提示词：
{{input.text}}
```

创建「自定义 JSON 数据」后，可填写：

```json
{
  "prompt": "{{input.text}}",
  "style": "cinematic"
}
```

点击「计算输出」会读取当前上游并显示本次结果。上游变化后可重新计算，下游 API 执行时也会计算最新上游。公共计算结果沿用单次同步大小限制，超限明确报错。

JSON 模板先通过标准 JSON 解析，再替换值，不会执行脚本。完整占位符保留字符串、数字、布尔、数组或对象的类型，并正确处理引号与换行。`{{image.dataUrl?}}` 的 `?` 表示缺少输入时省略这个字段；没有 `?` 的必需输入缺失则报错。禁止通过原型属性访问数据。

公共 JSON 使用 `{{image.fileId}}` / `{{audio.fileId}}` 表示附件引用。隐私 API 的完整 JSON 字段可以使用 `dataUrl`，服务器会读取经过鉴权、完整性验证的附件并流式编码，避免在内存中展开整个大文件。

## 生图、提示词优化和视频

内置模板参考本地 `ComfyUI-API-Nodes` 的图片 / LLM 节点与 `ComfyUI-AutoDL-H3` 的视频 API 参数；它们是可修改的配置起点，不是服务器上的 ComfyUI Python / GPU 工作流。

- **OpenAI 兼容生图**：模型、提示词、尺寸、质量；请求地址默认 `/v1/images/generations`。具体模型与尺寸必须由所用服务商支持，可修改地址和 JSON。
- **参考图对话请求**：图片输入连接参考图，文本输入连接提示词，发送包含 `image_url` 的对话 JSON。需要支持这种请求格式的模型 / 中转服务，不等同于 multipart 的 `/images/edits`。
- **提示词优化**：配置模型和系统指令；其私有文本结果可以继续接入自己的生图或视频节点。
- **AutoDL H3 视频**：提示词、时长、分辨率、可选图片和音频；提交至 `minimax_h3_image_audio_to_video_v2_15s`，任务状态通过 `/result/{task_id}` 查询。
- **自定义 API 请求**：自行配置 HTTPS URL、请求方法、正文格式、自定义请求头与认证方式；可启用异步任务查询并设置任务 ID 的响应路径。

表单中的「提示词」在没有文本输入连线时使用，有连线时优先采用上游文本。参数通过 `{{params.变量名}}` 引用，可在「请求配置与自定义参数」中添加或修改名称、显示标签和类型。

「服务管理」的域名白名单开关默认开启，沿用原有允许域名。开启时仅允许白名单中的完整域名；关闭时允许黑名单以外的公网域名，黑名单也阻止其子域。两份名单可分别编辑，点击「保存域名规则」后一起保存，切换不会清空。API 与结果媒体使用同一规则；白名单模式下，媒体在另一域名时也需加入。两种模式均只接受 HTTPS 443，并继续拒绝内网、云元数据地址和重定向。

视频生成使用短请求：点击「提交新任务」获得并加密保存任务 ID；之后点击「查询任务状态」仅查询已有任务，不重新提交。页面关闭后可以重新打开隐私节点继续查询。每次 HTTP 请求沿用 120 秒超时，上游生成期间不持有服务器的并发处理槽。

## 请求格式与认证

「请求配置与自定义参数」支持 GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS。GET / HEAD 不发送正文，查询参数可直接写入 URL，URL 中的占位符会自动编码。

| 正文格式 | 配置方法 |
| --- | --- |
| JSON | 填写 JSON 模板，完整占位符保留原始数据类型；附件可按流编码为 data URL |
| URL 编码表单 | 填写字段名与值组成的 JSON 对象，数组发送为同名重复字段 |
| multipart 文件表单 | 同样填写 JSON 对象；完整附件占位符发送为文件，支持数组重复字段、纯文本字段和空表单 |
| 原始文本 / XML | 填写文本模板及 Content-Type，例如 `application/xml`；按原样替换文本，不自动执行 XML 转义 |

例如，文件表单可填写：

```json
{
  "model": "服务商支持的模型名",
  "prompt": "{{input.text}}",
  "image": "{{image.dataUrl}}"
}
```

连接的附件会先验证加密文件完整性，再按流传给供应商，生成标准 multipart 边界与长度；不会先展开为整段 base64 或在磁盘保存明文。URL 编码表单和原始文本不能承载附件对象，请选择 JSON 或文件表单。供应商仍可另行限制其接受的文件大小和字段名称。

认证方式可选自动、原样请求头或不使用 API 密钥。自动模式对 `Authorization` 加 `Bearer`，其他密钥头按原值发送；原样模式可填写完整 `Basic …` 等值。额外请求头支持版本号等字段，禁止覆盖 Host、Cookie、Content-Length、连接与代理头，也拒绝换行注入。Content-Type 由所选正文格式生成，原始文本模式可单独填写。

## 保存模板和发布结果

配置好节点后点击「另存节点模板」，填写名称。模板出现在「我的模板」中，可反复创建新节点、修改并另存；不再使用时可删除模板，已创建的节点仍保留。模板按账户加密保存，API 密钥不会复制，自定义请求头默认也清空值；公开的固定版本号可关闭「模板中清空」。创建新请求节点后需重新填写密钥。模板正文和备注也可能包含私有信息，请只在自己的模板中维护。

响应中的图片、视频、音频可以选择字段后预览。外部媒体通过服务端鉴权代理读取，浏览器不直接携带密钥访问第三方媒体地址。原始响应可单独展开查看。

需要共享时，选择「发布所选媒体」或「预览并发布文本」，核对字段和公开名称后确认。文本可使用 `$text` 选择模型文本，也可使用 `choices.0.message.content` 等 JSON 字段路径。媒体会复制为当前画布的加密文件；只有已获得画布访问权限的账户可以下载。

发布只公开明确选择的字段，不复制 API 配置、密钥或响应的其他字段。隐私结果并不因连线或保存模板而自动公开。已经分享出去的内容无法从他人的截图和副本中收回。

## 上传和协作鼠标

文件默认上限为 **500 MiB（524,288,000 字节）**。管理员在「服务管理」直接修改，对新上传生效；既有大文件的下载不受后续调小影响。附件限制与 20 MiB 的 API JSON / 文本响应限制相互独立，上游 API 也可能有自己的请求大小限制。

每位在线协作者的鼠标显示用户名和稳定颜色，支持不同缩放与平移位置。鼠标按 150 ms 合并同步，属于临时状态，不写入画布历史；同账户多个标签页只显示一个标记，离开画布、失焦、标签页隐藏或断开后移除。
